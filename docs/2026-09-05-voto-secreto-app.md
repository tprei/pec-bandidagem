### Step 3. Link codec `assets/elo.js`

Pure module, no DOM, importable from Node tests. Postura travels in the route segment (`nao`|`voto`), everything else in the id.

```js
export const ALFABETO = "0123456789ABCDEFGHJKMNPQRSTVWXYZ"; // Crockford base32
export const UE_PARA_UF = { 1: "AC", 2: "AL", 3: "AP", 4: "AM", 5: "BA", 6: "CE", 7: "DF", 8: "ES", 9: "GO", 10: "MA", 11: "MT", 12: "MS", 13: "MG", 14: "PA", 15: "PB", 16: "PR", 17: "PE", 18: "PI", 19: "RJ", 20: "RN", 21: "RS", 22: "RO", 23: "RR", 24: "SC", 25: "SP", 26: "SE", 27: "TO", 28: "BR" };
export const MODELOS = ["cabine", "cedula"];          // wire index 0/1
export const TIPOS = { C: "candidato", D: "duelo", P: "pauta", L: "lista" };
const BITS_REF = 27;  // ue 5 bits (1..28) + seq 22 bits
```
`sq` (TSE `SQ_CANDIDATO`) is `ue * 1e10 + seq`; verified: every UF file's rows share one prefix (AC 1 … SP 25, TO 27, BR 28) and `seq` ranges 2,530,014-2,554,304 nationwide (< 2^22 = 4,194,304). `ref(sq) = (ue << 22) | seq`; encoder throws `RangeError` if `ue` not in `UE_PARA_UF` or `seq >= 2**22`.

Bit layouts (MSB first, packed in a BigInt, then base32 with fixed length `ceil(bits/5)` chars, left-padded with `0`), prefixed by the tipo letter:

| tipo | fields | bits | chars |
| --- | --- | --- | --- |
| `C` | modelo(1) motivos(8) ref(27) | 36 | 1+8 |
| `D` | modelo(1) refNao(27) refSim(27) | 55 | 1+11 |
| `P` | modelo(1) eixo(4) n(4) n×ref(27) | 9+27n | 1+ceil((9+27n)/5) |
| `L` | modelo(1) n(4) n×ref(27) | 5+27n | 1+ceil((5+27n)/5) |

`eixo` and each `motivos` bit are the position of the eixo in `indice.eixos` (current order: blindagem, jornada, anistia, trabalhista, clt, previdencia, eletrobras, ricos). That order is part of the wire format: `data/curadoria.json` eixos may only be appended, never reordered (state this in README). `n` is 1..9 faces.

Exports:
```js
export function codificar(post): string
// post: { tipo, modelo, sq?, motivos?: number[] (eixo indexes), nao?: sq, sim?: sq, eixo?: number, faces?: sq[] }
export function decodificar(id: string): null | { tipo, modelo, sq?, motivos?: number[], nao?, sim?, eixo?, faces?: sq[] }
export function ufDoSq(sq): string | undefined      // UE_PARA_UF[Math.floor(sq / 1e10)]
export function montarUrl(postura, id): string      // `https://votosecreto.com.br/#/${postura}/${id}`
export function textoLink(postura, id): string      // `votosecreto.com.br/#/${postura}/${id}` (display, QR encodes montarUrl)
export function extrairRota(texto): null | { postura, id } | { sq }  // parses a pasted/scanned string: matches /#\/(nao|voto)\/([0-9A-Za-z]+)/ or /#\/ficha\/(\d+)/
```
`decodificar` uppercases input and maps `I`/`L`→`1`, `O`→`0` before lookup; returns `null` on unknown tipo letter, non-alphabet char, wrong length for the tipo, `n` outside 1..9, `ue` not in `UE_PARA_UF`, or motivos with more than 4 bits set. Decoded `motivos` is the sorted list of set bit indexes. `codificar` throws `RangeError` on more than 4 motivos or `faces.length` outside 1..9.

Tests `tests/elo.test.mjs` (`node --test tests/`): round-trip each tipo with real sqs (`250002541303` SP, `10002532416` AC, a BR sq from `data/dex/BR.json`); `C` with motivos `[0,2,5,7]` gives 9 chars; `L` with 9 faces gives 51 chars; `decodificar("Z000")` is `null`; `decodificar` of a `C` id with a trailing char is `null`; lowercase and `O`/`I` substitutions decode equal to canonical; `extrairRota("Veja https://votosecreto.com.br/#/nao/C0ABCDEF1 agora")` returns `{ postura: "nao", id: "C0ABCDEF1" }`.
